# TypeScript Practice Repository

## Overview

This repository contains a collection of TypeScript practice problems and blog posts aimed at improving core TypeScript fundamentals and understanding of object-oriented programming concepts.

The focus of this repository is on learning through simple, practical examples that cover important concepts like generics, utility types, functions, and class-based programming.

---

# 📝 Blogs

## Blog 2-: Pick & Omit in TypeScript

Pick and Omit are utility types in TypeScript that help reduce code duplication by creating new types from existing ones.

* `Pick` is used to select specific properties from a type
* `Omit` is used to remove specific properties from a type

They help keep code DRY (Don’t Repeat Yourself) and make type management easier in large applications.

## Blog 4: OOP in TypeScript

Object-Oriented Programming (OOP) helps organize code using classes and objects, making large applications easier to structure and maintain.

It is based on four main pillars:

* Encapsulation
* Inheritance
* Polymorphism
* Abstraction

These principles help improve code reusability, readability, and scalability in real-world applications.
